# Dodge Me!

Although the name is Dodge Me, the one dodging is the player! There's the Killer Ball, basically a red ball that bounces off the walls, everytime it bounces it becomes faster and faster, so it'll be harder to get a higher score!

The original tutorial was given by LeMaster Tech, great tutorial series! I made it a bit more pleasant to the eye, but the original concept is all his.

## How to use
To be honest I only tested it on Arch Linux (I use Arch btw) but I think it should work on Windows too. Basically just execute the code file found in the dist folder. Simple enough isn't it? In my case I did it in my Downloads folder, so I did:



cd Downloads/pygame/dist

./code
